# COMPREHENSIVE PROJECT REPORT: MULTIMODAL EMG-EEG GESTURE RECOGNITION SYSTEM

## PROJECT OVERVIEW
This project develops and evaluates a multimodal approach to gesture recognition by combining Electromyography (EMG) and Electroencephalography (EEG) data. The research implemented various deep learning architectures including CNN, LSTM, and hybrid models to process and classify hand gestures from both EMG and EEG signals independently, culminating in a late fusion multimodal approach that achieved superior classification accuracy.

## DATA SOURCES
- Primary dataset from Mendeley Data Repository (DOI: 10.17632/m6t78vngbt.1)
- 8-channel EMG data collected from Thalmic Labs Myo Armband
- 8-channel EEG data collected from OpenBCI device
- Data from 10 subjects performing 7 distinct gestures with multiple repetitions

## PROJECT COMPONENTS

### 1. Data Preprocessing Framework
A comprehensive preprocessing pipeline was developed to transform raw EMG and EEG recordings into machine learning-ready datasets:
- Data extraction and cleaning from CSV files
- Feature extraction and normalization
- Windowing techniques for temporal data
- Data validation and integrity checking
- Output as structured CSV files for subsequent analysis

### 2. EMG-Based Gesture Classification
Three deep learning architectures were implemented and compared for EMG-based gesture classification:
- 1D Convolutional Neural Network (CNN)
- Long Short-Term Memory (LSTM) network
- Hybrid CNN-LSTM model
The hybrid model achieved the highest accuracy (96.24%) on the test set.

### 3. EEG-Based Gesture Classification
An advanced CNN-LSTM hybrid model with attention mechanism was developed for EEG signal processing:
- Effective at capturing both spatial and temporal patterns in EEG data
- Achieved 93.47% validation accuracy
- Demonstrated potential for brain-computer interface applications

### 4. Multimodal EMG-EEG Integration
A late fusion architecture was implemented to combine information from both EMG and EEG signals:
- Separate CNN branches for each modality
- Feature concatenation followed by fully connected classification layers
- Time alignment with a 35ms delta between modalities
- Achieved exceptional performance with 99.23% test accuracy

## KEY FINDINGS
1. Multimodal approach significantly outperformed single-modality models
2. Late fusion effectively leveraged complementary information from muscle activity and brain signals
3. Deep learning architectures successfully captured both spatial and temporal aspects of biosignals
4. The system demonstrated robust performance across different subjects and gestures
